### Financial Calculator v1.2

A Python-based financial calculator that accepts monthly income and expenses, calculates remaining monthly income, and analyzes the percentage of income being used for expenses.

**Features:**
- Accepts monthly income and expense input
- Calculates remaining monthly income
- Formats financial results as currency
- Calculates expenses as a percentage of income
- Provides feedback based on expense levels
- Validates user input
- Prevents zero or negative income
- Handles invalid input without crashing
- Uses reusable functions to organize program logic

**Python Concepts Used:**
- Variables
- User input
- `float()` data conversion
- Mathematical operations
- F-strings and number formatting
- `if`, `elif`, and `else`
- `while` loops
- `try` and `except`
- `ValueError` handling
- `break` and `continue`
- Functions
- Parameters and arguments
- `return`
- Code refactoring

**Version History:**
- **v1.0** - Created the initial financial calculator with calculations and conditional analysis
- **v1.1** - Added input validation, exception handling, and protection against zero income
- **v1.2** - Refactored the program using reusable functions and improved code organization
